# SAFE-04 밀폐공간 작업 기준

> 실습용 가상 사내 규정입니다. 실제 작업에는 회사 규정과 관련 법령을 따르세요.

## 1. 작업 전
1. 밀폐공간 작업허가서를 발급받는다.
2. 내부에 남은 화학물질을 비우고, 연결 배관을 차단(맹판 설치)한다.
3. 진입 직전 산소·가연성가스·유해가스 농도를 측정한다.
   - 산소 18% 이상 23.5% 미만
   - 가연성가스 폭발하한(LEL)의 10% 미만
   - 황화수소 10ppm 미만
4. 기준을 넘으면 환기 후 다시 측정한다.

## 2. 작업 중
1. 외부에 감시인을 반드시 1명 이상 배치한다.
2. 작업 중에도 계속 환기하고, 가스 농도를 연속 측정한다.
3. 이상이 느껴지면(어지러움, 냄새) 즉시 밖으로 나온다.

## 3. 구조 원칙
- 쓰러진 사람을 구하러 **보호구 없이 들어가지 않는다**. 밀폐공간 사망 사고의 상당수는 구조하러 들어간 사람에게서 발생한다.
- 공기호흡기를 착용한 구조자만 진입한다.
