# SAFE-02 화학물질 누출 대응 절차

> 실습용 가상 사내 규정입니다. 실제 작업에는 회사 규정과 관련 법령을 따르세요.

## 1. 즉시 조치 (발견자)
1. 주변 작업자에게 큰 소리로 알리고, 바람이 불어오는 쪽(풍상)으로 대피한다.
2. 가능하면 점화원(불꽃, 전기 스위치 조작)을 제거하되 **스스로 위험해지면서 하지 않는다**.
3. 비상연락망(가상 내선 119)으로 안전관리자에게 물질명·누출량·위치를 보고한다.

## 2. 소량 누출 (1L 이하, 사전 교육 이수자만)
1. SAFE-01 기준 보호구를 착용한다.
2. 흡착포 또는 흡착제로 바깥쪽에서 안쪽으로 둘러싸듯 흡수한다.
3. 산·염기는 전용 중화제를 사용하고, 물을 직접 붓지 않는다.
4. 사용한 흡착포는 밀폐 용기에 담아 '지정폐기물'로 표시한다.

## 3. 대량 누출 또는 가스 누출
1. 직접 처리하지 말고 즉시 대피한다.
2. 비상대응팀이 도착할 때까지 출입을 통제한다.
3. 암모니아·황화수소 등 독성 가스 누출 시에는 공기호흡기를 착용한 비상대응팀만 진입한다.
